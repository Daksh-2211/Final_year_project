Website: Promotion Bar

Quick non-intrusive Space for Latest updates & Announcements

The module adds an announcement bar on any webpage of your Odoo website. You can display single or multiple promotions and updates on the same announcement bar.

Any upcoming promotions, season sales, big deals day or important event announcement can be added to the website. The promotion bar offers excellent visibility without being obtrusive.

The promotional bar can be set to be visible to all the visitors or only to the logged in customers.

Features:

  • The module facilitates the addition of a promotional bar to the Odoo website.
  • The announcement bar can be added on the top, bottom, left or right side of any desired webpage(s).
  • The admin can choose to show single or multiple announcements. If multiple announcements are displayed, they run in circulation in the promotion bar- one after the another.
  • The duration of the promotion bar message can be set in the Odoo backend.
  • The admin can also choose to enable/disable to show a popup on clicking the announcement.
  • Moreover, the visibility can be managed as public users (all visitors) or portal users (those who are logged in to their website accounts).
